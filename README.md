## 项目介绍

物联网（Internet of Things, IoT）作为信息技术与通信技术领域中的一项重要技术，近年来取得了显著的发展。物联网是指通过互联网连接、感知和通信技术，使各种设备和系统能够相互交互、收集数据，并实现智能化、自动化的网络。这些设备可以是各种各样的物理对象，如传感器、执行器、嵌入式设备等。随着科技的进步，物联网在各行各业得到广泛应用，为人们的生活和工业生产提供了更加便捷和智能的解决方案。

随着物联网技术的发展，其规模逐渐扩大，尤其在工业中，物联网系统中的设备数量呈爆炸式增长。设备数量的增加使得我们能够更精细地了解和控制周围环境，但按照传统方法维护这些静态传感设备变得越来越昂贵。如何为这些静态设备提供低成本的、持续的能源供应成为一个日益突出且重要的问题。

得益于人工智能的不断发展成熟，**部署移动 Agent 给物联网设备充电并使用人工智能算法进行路径规划**已逐渐变得可行。该问题可以形式化为完全带权图。单个机器人的路径规划可以被形式化为旅行商问题（Travelling Salesman Problem, TSP），即选择一条路线经过所有节点一次，并使总路线长度最小。对于解决多旅行商问题（Multiple Trravelling Salesmen Problem, mTSP）可以运用分治的思想：对于有 n 个机器人的 mTSP 问题，将图划分为 n 个子图，每个子图便退化成了单机器人的 TSP 问题。

然而，目前的研究仍存在一些不足之处。首先，绝大部分 TSP 的研究均是静态 TSP 问题，而对本问题来说，**机器人到达某设备处需要停顿一段时间对设备进行充电，该时间是不定的，且往往不可忽略：当前设备电量越多，充电时间越短；反之，充电时间越长**。因此该问题是一个具有动态需求的 TSP 问题。其次，对考虑动态需求的TSP问题的大部分研究只考虑了单个机器人的 TSP 问题，对具有动态需求的多机器人的 TSP 问题没有一个成熟的算法。另外，对一般的 TSP 问题的研究很难考虑到机器人可能需要多次往返基站节点进行充电的情况。因此，现有研究在该问题上仍有很大提升完善的空间。

综上所述，本项目的主要贡献如下：<br>
(1) 我们提出了一种**面向多移动 Agent**的**动态**服务需求路径规划框架，通过两阶段推理机制有效解决了物联网设备充电场景下的多机器人协同路径规划问题。<br>
(2) 我们设计了**基于强化学习**的图划分网络和对应优势函数，结合**多头注意力机制**，实现了对多 Agent 任务区域的合理划分，并提出了并行推理策略以提升模型训练与推理效率。<br>
(3) 实验表明，我们的方法在动态服务需求的多旅行商问题中表现出优越的规划性能与高效的计算性能。得益于所提出的并行推理策略 Dynamic Masking，我们的模型在保持高质量解的同时，**推理速度较基线方法提升了约 73.5% (4.25s vs 16.02s)**，为物联网设备能源维护提供了高效、低成本的解决方案。

> **关键词**：强化学习、多头注意力机制、图神经网络、旅行商问题

## 模型结构
本项目基于论文《A learning approach for multi-agent travelling problem with dynamic service requirement in mobile IoT》提出的 GAPN 网络架构进行扩展。原论文针对单 Agent 场景下的动态服务需求路径规划问题提出了解决方案，本项目在此基础上采用了**两阶段推理框架**来解决多 Agent 场景：
1. **图划分阶段** <br>
   - 使用自定义网络将服务区域划分为多个子图
   - 每个子图对应一个 Agent 的专属服务区域
2. **路径规划阶段** <br>
   - 各子图通过独立的 GAPN 网络进行路径优化
   - 支持并行计算以提高效率

### 图划分阶段详解

#### **编码器**
通过图同构网络生成：
   - 节点级嵌入 $f^N$ （Node Embeddings）
   - 全图嵌入 $f^G$ （Graph Embedding）

#### **Agent 分析模块(Agent Anaylsis Module, AAM)**
1. 将全图嵌入 $f^G$ 作为 Query，节点嵌入 $f^N$ 作为 Key/Value
2. 输出各 Agent 独特的嵌入表示 $f^A$

#### **解码器**
1. 计算 Agent 嵌入与节点嵌入的相关性
2. 采用放大双曲正切（Scaled tanh）激活
3. 通过 Softmax 输出节点分配概率
4. 最终输出 $m$ 个子图 $\{G_i\}^m_{i=1}$

### 图划分网络训练
**强化学习架构**<br>
将划分网络任务形式化为单步马尔可夫决策过程（MDP），奖励函数 $R = -\max(\mathcal{L}_{\text{GAPN}})$，即第二阶段各子图损失最大值的相反数。


**负载均衡**<br>
使用上述奖励的 Policy Gradient 算法可自动实现负载均衡，无需显式约束子图节点数。不仅允许子图间合理数量差异（提升模型泛化性），奖励的设计还能天然避免策略退化。


### 优势函数设计以及与 GRPO 的对比

本文采用优势函数设计 $A_t = R(t) - \bar{R}$，其中 $\bar{R}$ 为组内奖励均值。优势函数与 GRPO 中的设计类似，均以组内相对回报为基线。使用该设计可在不显著增加模型复杂度的前提下降低梯度估计方差。

**组内标准差归一化的取舍**
在 GRPO 中，优势函数通常以组内相对回报为基础进行估计：

$$
\hat A_t^{\text{GRPO}} = \frac{R(t)-\bar R}{\hat\sigma(x)}
$$

可以注意到本文使用的算法和 GRPO 的相似性，但两者也不完全相同。具体来看，使用 $A_{t1} = R(t) - \bar{R}$ 而非 $A_{t2} = \dfrac{R(t) - \bar{R}}{\hat{\sigma}}$（其中 $\bar{R}$ 为组内奖励均值， $\hat{\sigma}$ 为组内奖励标准差）可能的好处如下：
- 评估噪声小。 在下游网络已充分收敛的前提下，给定分组后奖励接近确定，**奖励评估引入的噪声很小**。因此不存在需要通过标准差归一化来压制的奖励随机性，该操作在本场景中收益有限。
- 无偏性。由 baseline 定理可知，减去与当前动作无关的基线不改变策略梯度的期望；而**除以组内标准差相当于引入了与样本相关的归一化因子，破坏了梯度估计的无偏性**。基于该理论又可以延申以下几点：
   - 收敛性。 本文问题为单步决策，且下游求解器已冻结，奖励仅由分组决定。因此理论上对于足够大的问题集，模型收敛后，组内方差趋于零（由于分组的离散性和问题集的规模，实验中观察到方差并不会非常接近零，仅呈现减小趋势）。除以标准差会**在训练后期将微小的组内差异放大**，导致策略在已收敛的解附近随机抖动。相反，使用 $A_{t1}$ 则优势函数随训练趋于0，梯度渐渐平缓。
   - 输入相关。 本文问题的特性决定了组内标准差与实例相关：对于存在宽松解的实例（如城市分布均匀），各种分组方案的结果相近，方差天然较小；而对于仅存在严格解的实例（如城市呈明显簇结构），分组方案差异显著，方差更大。显然，前者很容易分出一个好解，后者很难分出一个好解。若除以标准差，等价于**给宽松实例赋予更高的隐式权重、压制严格实例的学习信号，与学习价值的分布恰好相反**。相反，使用 $A_{t1}$ 则使梯度幅度正比于实例上的潜在改进空间，将学习资源自动集中到分组决策真正重要的实例上。
   - 训练初期的稳定性。 本文的奖励为负的最大子回路长度，对个别子回路的爆炸高度敏感。此时组内标准差本身波动剧烈，且被离群坏解所支配。使用 $A_{t1}$ 时，**坏分组受到的惩罚与其造成的实际性能恶化成正比；而除以标准差会压缩此类大偏差样本的梯度，削弱对子路爆炸的惩罚力度**。

### Dynamic Masking
针对以往工作由于第二阶段串行推理导致计算效率低下，本文创新性地提出了一种并行推理策略Dynamic Masking，通过尾部补全节点实现子图对齐，利用掩码机制保证GAPN推理不受补全节点影响。
